# Processed Outputs Directory

This directory is designated for storing structured, aggregated, and compiled business intelligence outputs.

## 📂 Expected Contents

Analytical assets generated by the API and processing layer placed here include:
* **`events.json`**: Historical database of tracking, entry, and dwell events compiled by the consumer loop.
* **`analytics.json`**: Calculated metric records, conversion funnel reports, and historical trajectories.
* **Analytical Exports**: Processed CSV summaries and Excel report outputs.

## ⚠️ Git Commit Exclusions

As per the Purplle Tech Challenge 2026 rules:
* All generated database files and event exports are strictly **excluded from being committed to GitHub**.
* The `.gitignore` file at the root of the project has been updated to ignore all generated files inside `data/processed/` while preserving the `.gitkeep` and this documentation.
