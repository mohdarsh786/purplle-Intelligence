# Point of Sale (POS) Data Directory

This directory is designated for storing the transactional sales logs generated by cash registers in the store. 

## 📂 Required Files

To run the sales conversion and data fusion engine, place the following file in this folder:

* **File Name**: `Brigade_Bangalore_10_April_26.csv`
* **Source**: Purplle Cash Register System / Tech Challenge Resources

## ⚠️ Git Commit Exclusions

As per the Purplle Tech Challenge 2026 rules:
* All transaction dataset files (`.csv`) are strictly **excluded from being committed to GitHub**.
* The `.gitignore` file at the root of the project has been updated to ignore `data/pos/*.csv`.
* Only the directory structure, the `.gitkeep` placeholder, and this documentation file should reside in the remote repository.
